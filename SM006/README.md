## 이번 변경
1. 관리자 화면의 **외부 화면 90° 회전** 버튼을 누를 때마다 배경과 사진 화면이 함께 90 → 180 → 270 → 360(0)도로 회전합니다. 메인 창과 Windows 디스플레이 설정은 유지합니다.
2. 관리자 메뉴에서 사진 저장 루트를 직접 입력하거나 폴더를 선택하고 **저장 루트 적용**을 누릅니다. 기본값은 `C:\ShineMung`입니다. 촬영 종료 후 다음 사용자 준비 화면에서 변경할 수 있습니다. 이전 백업 작업은 당시 저장 루트를 그대로 사용합니다.
3. 촬영 시작 시 `날짜\강아지이름_HHmmss_fff` 폴더를 정합니다. 자정이 지나도 같은 촬영은 같은 폴더를 사용하며, 같은 시각의 폴더가 이미 있으면 번호를 붙입니다.
4. 종료 시 촬영 파일(JPG/JPEG 및 RAW)과 Printed 사본을 모두 Google Drive에 업로드하고 크기·MD5를 검증한 뒤, 그 촬영에 속한 로컬 JPG/JPEG만 삭제합니다. **CR3와 다른 RAW는 PC에 보관합니다.** 오류/취소 시 미완료 작업을 보존하고 다음 실행 또는 백업 재시도로 이어갑니다.

## 인쇄 보관
추천 8장의 원본 파일을 별도 스냅샷으로 복사하고, 그 파일로 기존 4컷 2매 인쇄를 수행합니다. Windows 인쇄 대기열 전송이 성공한 경우 Printed에 보관해 촬영 종료 시 함께 업로드합니다. 실제 용지 출력 성공 여부는 프린터에서 확인해야 합니다.
다시 인쇄하면 인쇄 회차별로 8장을 추가 보관합니다. 인쇄 전송 중 오류가 나면 `.print-pending-*` 폴더의 임시 사본은 확인을 위해 유지합니다. 전송 완료 후 보관 중 중단된 작업은 기록을 이용해 복구합니다.

## 기존 기능
- ESC: 어느 WPF 창에서든 종료 요청. 진행 중 전송을 정리하고 백업은 중지해 다음 실행에 재개합니다. 장치 응답 시간 초과 안내 후 ESC를 다시 누르면 강제 종료합니다.
- 카메라 연결을 확인한 후 강아지 이름을 입력합니다.
- 관리자 메뉴에서 Google Drive 연결/재연결/상태 확인을 할 수 있습니다. 계정은 `nobug007@gmail.com`입니다.
- SM005 인증을 최초 실행 때 가져옵니다. 인증/설정/백업 기록은 `%LOCALAPPDATA%\ShineMungSM006`에 저장하며 인증 파일을 공유하지 마세요.
- 기존 배경 선택, 20분 촬영, 추천 사진, DS-RX1 계열 인쇄 기능을 유지합니다.
