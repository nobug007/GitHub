# SM006 작업 규칙
- 원본 SM005를 수정하지 않는다. C#/.NET 8 WPF x64, 기존 Canon SDK와 인쇄 동작을 유지한다.
- 빌드/검증: build.ps1 -Verify. x64 C:\Program Files\dotnet\dotnet.exe 사용.
- 관리자 회전은 두 외부 출력만 90/180/270/0도 순환. 메인 창 및 Windows 디스플레이 설정은 회전하지 않는다.
- 기본 저장 루트 C:\ShineMung. 관리자에서 다음 촬영 루트 변경. 시작 시 날짜/강아지이름_HHmmss_fff 폴더를 확정하고 세션 동안 고정한다.
- Google 내 드라이브 ShineMung/날짜/강아지이름_시간에 모든 촬영 사진 백업. Printed는 인쇄 대기열 전송 성공한 8장의 스냅샷을 보관한다.
- 세션 전체 파일과 Printed 업로드·크기·MD5 확인 이후 JPG/JPEG만 PC에서 삭제. CR3 및 RAW는 절대로 자동 삭제하지 않는다. 이전 버전 사진/카메라 SD 카드/임의 파일 삭제 금지.
- 실패/취소 시 원본 보존 및 durable journal 재시도. 인쇄 보관 복구 기록은 유지한다. 자동 테스트에서 실제 사용자 파일 삭제나 용지 출력 금지.
- 모든 EDSDK 호출은 카메라 전용 STA에서만 실행. Host는 촬영 시작 버튼에서만 허용하고 종료/시간 만료 시 Camera 복원 및 세션 정리한다.
- 인증은 LocalAppData에만 저장하고 토큰/비밀값을 출력하거나 저장소에 넣지 않는다.
- 카메라 실촬영, 3개 모니터 배치 및 실제 인쇄는 현장에서 확인해야 한다.
