# 샤인멍 · 3 Screen

Windows용 단일 프로세스 프로그램입니다. 메인 화면(로고와 제어판) 1개와 전체화면 이미지 출력 창 2개를 제공합니다.

## 실행

`ShineMung3Screen.exe`를 더블클릭합니다. 설치나 인터넷 연결 없이 실행됩니다. `assets` 폴더를 실행 파일과 함께 보관하세요.

1. Windows 디스플레이 설정이 **확장** 모드인지 확인합니다.
2. 각 카드에서 서로 다른 모니터를 선택합니다. 기본값은 주 모니터=메인, 왼쪽부터 나머지=강아지/배경입니다.
3. **적용 / 출력 시작**을 누릅니다.
4. **모니터 식별**은 각 모니터에 장치 이름과 해상도를 2.5초 동안 표시합니다.
5. 이미지 변경으로 JPG/PNG/BMP/GIF 파일을 지정할 수 있습니다. GIF는 정지 이미지로 표시됩니다.

- **F11**: 메인 화면 제어판 숨기기/보이기. 로고만 표시하려면 사용하세요.
- **Esc**: 출력 중지 후 제어판 표시.
- **Alt+F4**: 메인 창에서 앱 종료. 출력 창에서는 해당 단축키가 출력 중지로 동작합니다.
- 전체 보이기는 비율 유지와 여백, 화면 채우기는 비율 유지와 가장자리 자름입니다.
- 모니터 연결 변경 시 출력을 중지하고 재배정을 요청합니다.
- 적용 시 설정이 `%LOCALAPPDATA%\ShineMung3Screen\settings.xml`에 저장됩니다.
- 모니터 장치명은 Windows의 DISPLAY 이름입니다. 식별 버튼을 이용해 물리적 위치를 확인하세요.

## 빌드와 검증

Windows .NET Framework 4.x와 기본 제공 C# 컴파일러를 사용합니다. 별도 SDK/NuGet 설치가 필요 없습니다.

```powershell
.\build.ps1
Start-Process .\ShineMung3Screen.exe -ArgumentList '--self-test' -Wait
Get-Content .\test-results.txt
```

자가 테스트는 모니터 3대에서 실제 창을 잠시 띄워 해상도/위치, 실시간 재배정, 중복 및 누락 배정 차단, 로고 모드, 출력 중지/재시작을 검증합니다. 사용자 설정을 변경하지 않습니다.

2026-09-24: 연결된 DISPLAY1(2880×1800), DISPLAY2/3(각 3840×2160)에서 자가 테스트 통과. 고해상도 배율을 반영하는 DPI 인식 매니페스트가 포함됩니다.
