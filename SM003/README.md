# 샤인멍 SM003

C# / .NET 8 x64 / WPF. 3Screen2를 기반으로 별도 구성했습니다.

## 실행
`Start.cmd`를 실행합니다. 빌드 및 검증은 `powershell -ExecutionPolicy Bypass -File .\build.ps1 -Verify`입니다.
Canon SDK 원본: `C:\GitHub\EDSDK_64\Dll`. 실행 폴더로 EDSDK.dll과 EdsImage.dll을 복사합니다.
3Screen2와 카메라를 동시에 사용하지 않도록 기존 앱과 실행 잠금을 공유합니다.

## 사용
- 첫 실행 화면에서 강아지 이름을 입력합니다. 준비 페이지 중앙에 이름만 표시됩니다.
- 자연 배경 12개 중 하나씩 클릭합니다. 처음에는 선택이 없고, 최근 선택한 서로 다른 2개를 선택 순서대로 표시합니다. 세 번째를 선택하면 가장 먼저 선택한 배경이 빠집니다. 이미 선택한 배경을 다시 누르면 가장 최근 순서로 이동합니다. 털 색 추천은 추천 표시만 바꾸며 선택하지 않습니다. 두 배경은 자동 적용되고 60초마다 교대합니다.
- 이름과 배경 2개를 고른 뒤 촬영 시작을 누릅니다. 카메라 설정 성공 후 촬영 페이지로 이동해 이름·남은 20분·카메라 연결 상태·현재 배경과 다음 전환까지 시간을 표시합니다. 카메라 셔터로 촬영하면 PC 저장 → 사진 화면 갱신 → 썸네일 추가 순으로 처리합니다.
- 현재 세션의 최근 100장 썸네일을 한 줄에 5장씩 표시하고 새 사진으로 자동 스크롤합니다. 사진을 누르면 노트북 화면 가로·세로 70% 크기의 팝업에서 선택한 사진만 봅니다. X 또는 Esc로 닫습니다. 새 사진이 들어와도 팝업의 선택 사진은 유지됩니다. 촬영 종료 후 ‘다음 촬영 준비’로 돌아갑니다. 100장을 넘어도 PC 원본은 삭제하지 않습니다.
- 관리자 메뉴는 매번 비밀번호 `3327` 입력 후 열립니다. 잘못 입력하거나 취소하면 열리지 않습니다. 메뉴: 메인 모니터 지정, 외부 두 화면 교환, 사진 가로/세로, 재연결, 테스트 사진, 종료.
- 원본: Windows 사진 폴더의 ShineMungSM003 / 날짜 / DOG_이름. 설정 및 로그: %LOCALAPPDATA%\ShineMungSM003.

## 20분 제한 및 절전 방지
메모리 카드 제거와 카메라의 카드 없이 셔터 작동 ‘사용 안함’ 설정을 전제로 합니다.
시작 시 SaveTo.Host와 PC 용량을 설정하고 읽어서 확인합니다. 20분 만료 시 SaveTo.Camera 복원 및 EdsCloseSession을 수행합니다. 진행 중 다운로드는 보존합니다.
앱 실행 중 Windows 자동 절전과 화면 꺼짐을 방지하고 종료 시 해제합니다.
카메라는 30초마다 ExtendShutDownTimer를 전송하며 종료 예고 이벤트에도 응답합니다. 대기 중에는 Camera 상태로 잠깐 세션을 열어 통신하고 Camera 설정을 재확인한 뒤 닫습니다. Host는 촬영 시작 버튼으로만 설정됩니다.
실제 전원 차단, 배터리 소진 또는 USB 분리는 소프트웨어로 막을 수 없습니다. 연결 복구는 자동 검색하지만 촬영 허용은 자동 재개하지 않습니다.

## 검증
자동 검증은 20분 만료/실패 복원/재시작 차단, 배경 교대, 사진 방향, 메인 타이머, 105장 추가 시 100장 유지, SDK 검색을 확인합니다.
실제 셔터 촬영 및 장시간 절전 방지는 연결된 장비에서 확인해야 합니다.

추가 배경은 내장 image_gen으로 생성했습니다. 파일과 최종 프롬프트: assets/backgrounds/generated-additions.json. 자동 검증 이미지: bin/Release/net8.0-windows/verification/setup.png, capture.png.

## SM003 사진 정리
촬영 페이지에 다음 버튼 2개를 추가했습니다. 인터넷 전송이나 외부 서비스 비용 없이 PC에서 분석합니다.

1. **흔들림·초점 불량 사진 삭제**: 현재 촬영 세션의 저장 완료된 사진 전체를 분석하고 흐림이 뚜렷한 사진을 Windows 휴지통으로 이동합니다. 휴지통에서 복원할 수 있습니다. 복원한 사진은 자동으로 현재 갤러리에 다시 추가되지는 않습니다. 실패한 파일은 목록에 남고 결과 개수가 표시됩니다. 카메라 SD 카드에는 접근하지 않습니다.
2. **추천 사진 8장**: 선명도와 노출 점수가 높은 순서로 고르되, 전체 구도와 중앙 영역이 비슷한 사진은 하나만 남겨 최대 8장을 표시합니다. 고유한 후보가 적으면 8장을 억지로 채우지 않습니다. 같은 버튼의 ‘전체 사진 보기’로 돌아갑니다. 팝업 확대도 그대로 사용할 수 있습니다.

- 분석 대상은 최근 100장에 한정되지 않고 현재 세션에 들어온 전체 사진입니다. 전체 보기의 표시 한도는 기존처럼 최근 100장입니다.
- 촬영 중에도 분석할 수 있습니다. 추천 분석 중 새 사진이 들어오면 다시 추천하도록 알립니다. 추천을 보는 동안 촬영하면 전체 보기로 돌아가 최신 사진까지 자동 스크롤합니다.
- JPEG/PNG/BMP 원본을 분석합니다. RAW는 작은 미리보기만으로 원본 초점을 판정할 수 없어 삭제·추천에서 제외하고 원본을 보존합니다. 테스트로 불러온 외부 파일은 삭제하지 않습니다.
- 중앙 70% 영역의 여러 구역에서 선명도를 평가하고 노출/대비를 함께 봅니다. 질감이 부족하거나 판정이 모호한 사진은 자동 삭제하지 않는 보수적인 기준입니다. 강아지 눈 초점, 표정, 구도에 대한 학습 모델은 아니므로 모든 실패 사진을 잡거나 미적인 최적 사진을 보장하지는 않습니다.
- 삭제·추천 결과 및 점수 로그: `%LOCALAPPDATA%\ShineMungSM003\analysis`.
- SM001 소스와 저장 폴더는 별도로 유지됩니다. SM003 사진: Windows 사진 폴더의 `ShineMungSM003`.
- 자동 검증은 흐림 판별, 질감 부족 사진 보호, 유사 사진 제외, 최대 8장 순위, 삭제 경로 제한과 오류 처리, 추천/전체 갤러리 전환을 추가 검사합니다. 테스트에서는 실제 사용자 사진을 삭제하지 않습니다.

### 불량 삭제 판정 보정
삭제 후보가 0장으로 남던 문제를 수정했습니다. 배경이 선명하고 중앙 피사체만 흐린 사진을 놓치지 않도록, 기존 전체 점수와 별도로 중앙 구역의 선명도·대비를 검사합니다. 1024px 정규화 기준 중앙 선명도 150 미만, 전체 선명도 180 미만이며 대비/노출이 유효한 경우 추가 삭제 후보로 분류합니다. 중앙이 단색인 경우는 이 추가 규칙에서 제외합니다. 추천 8장 정렬·유사도 규칙은 이전과 같습니다.
결과는 ‘불량 판정 / 휴지통 이동 / 실패 / 분석 제외’로 표시하고, 대상이 없을 때는 ‘삭제 대상 없음’을 명시합니다. 점수 로그에 CenterSharpness와 CenterContrast가 추가됩니다.
자동 검증은 테스트 파일의 실제 Windows 휴지통 이동도 확인합니다. 사용자 촬영 원본에 대한 회귀 확인은 읽기 전용 분석으로 수행했습니다.

## SM003 인화 출력
촬영 페이지에서 추천 사진이 정확히 8장 표시될 때 **Print · 4컷 × 2장** 버튼이 활성화됩니다.
- 한 장 크기: 가로 6인치 × 세로 4인치. 사진 4개를 2×2로 배치합니다.
- 첫 인화지: 추천 1~4번, 둘째 인화지: 추천 5~8번. 2페이지를 1부로 한 인쇄 작업에 전송합니다.
- 출력 대상: 등록된 DS-RX1HS 또는 DS-RX1. 이 PC에서는 DS-RX1로 등록되어 있습니다. 기본 프린터로 우회하지 않습니다.
- 용지 옵션: 드라이버의 `(6x4)` / PC. 표준 절단 CUT_STANDARD를 지정해 2inch cut은 끕니다. 4인치 길이마다 기본 절단하도록 요청합니다. 6×8 용지나 2inch cut 레이아웃을 만들지 않습니다.
- 4×6 규격에 맞는 DNP 인화지·리본이 장착되어 있어야 합니다. 실제 절단과 용지 배출은 프린터 드라이버/장비가 수행합니다.
- 썸네일 대신 EXIF 방향을 적용한 원본으로 300dpi 1800×1200 이미지를 만듭니다. 각 사진은 비율을 유지하고 여백을 둬 얼굴 잘림을 방지합니다. 드라이버의 약간 큰 도련 크기를 검증하고 실제 인쇄용 이미지를 중앙 배치합니다.
- 이번 인쇄 작업에만 용지·절단·1부·1페이지/장 설정을 적용하며 Windows 기본 설정은 변경하지 않습니다.
- 인쇄 중 중복 클릭, 삭제 및 다음 세션 전환을 막습니다. 촬영과 20분 카운트다운은 계속됩니다. 클릭 당시 추천 8장이 인쇄되므로 새 사진 수신의 영향을 받지 않습니다.
- ‘전송 완료’는 Windows 인쇄 대기열 전송 완료를 뜻합니다. 종이 출력 완료를 뜻하지 않습니다. 전송 중 오류가 발생하면 자동 재출력하지 않으므로 대기열과 실출력 수량을 확인해 주세요.
- 추천이 8장 미만이면 Print가 비활성화됩니다. 추가 촬영 후 다시 추천하세요.

검증: 2개 인쇄 이미지, 2페이지 XPS 생성 및 재열기, 등록 프린터의 용지·표준 절단 설정 재검증, Print 버튼 활성/비활성 확인. `verification/print-1.png`, `print-2.png`, `print-preview.xps`, `print-ticket.xml`, `printer.txt`를 확인할 수 있습니다. 자동 검증은 실제 프린터에 인쇄물을 전송하지 않습니다.
