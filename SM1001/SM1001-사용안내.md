# SM1001 두 카메라 촬영

실행: Start.cmd

- EOS R5 Mark II 또는 EOS R8 한 대 + EOS 200D 한 대를 USB로 연결합니다. 두 대 모두 준비되어야 이름 입력과 촬영 시작이 가능합니다. EOS Utility는 종료합니다.
- 촬영 시작 버튼: 두 카메라에 RAW + Large Fine JPEG와 PC 저장을 설정합니다. 200D는 라이브뷰를 켜서 미러를 올립니다. 단순 연결 시에는 미러를 올리지 않습니다.
- 종료 / 20분 만료 / ESC: 200D 라이브뷰를 끄고 미러를 내리며, 두 카메라의 저장을 Camera로 복원합니다. 연결이 끊기면 물리적 복원을 확인할 수 없으므로 카메라 전원과 미러를 확인합니다.
- 미러리스의 첫 JPEG/RAW 전송 이벤트에서 200D에 셔터 명령을 보냅니다. 같은 사진의 JPEG와 RAW로 두 번 촬영하지 않습니다. 이는 USB 이벤트를 이용하므로 노출 시점이 정확히 같지는 않습니다. 200D가 바쁘면 실패를 오른쪽 제목과 로그에 표시하며 중복 노출 방지를 위해 자동 재촬영하지 않습니다. 단사 촬영을 권장합니다.
- 메인 왼쪽/오른쪽에는 각 카메라의 가장 최근 사진이 표시됩니다. 연사나 실패 시 두 사진을 동일 노출 쌍으로 보장하지 않습니다. 외부 사진 화면과 기존 추천/인쇄 갤러리는 미러리스 사진을 사용합니다.
- 두 카메라 파일은 동일 날짜/강아지 세션 폴더에 Mirrorless_ / 200D_ 접두어로 구분합니다. 200D RAW는 CR2, 미러리스 RAW는 CR3로 원본 확장자를 유지합니다.
- 두 카메라 파일 모두 기존 Drive 백업 대상입니다. 전체 업로드 및 해시 확인 후 JPEG만 삭제하고 RAW는 보관합니다. Printed 8장 보관도 유지합니다.
- SM006의 Drive 인증을 사용자 LocalAppData에서 최초 실행 시 가져옵니다. 인증 파일은 소스에 저장하지 않습니다.

검증: build.ps1 -Verify. 카메라 역할 선택, RAW/JPEG 순서별 셔터 중복 방지, 역방향 트리거 방지, 세션 초기화, 기존 UI/백업/인쇄 모의 검증을 수행합니다. 검증에서는 실촬영이나 실제 인쇄를 하지 않습니다.
실장비에서 확인할 항목: 200D 라이브뷰 미러 상승/하강, 두 기종 조합별 RAW+JPEG 4개 저장, 셔터 지연, 종료/시간 만료/USB 분리 복원. 현재 자동 검증에서 카메라는 한 대만 검색되어 두 대 실촬영은 검증하지 않았습니다.
